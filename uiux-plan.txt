4) Main User Flows
4.1 User Flow A — CEO / Clinic Owner Flow
Goal: understand value quickly and book a consultation.
Homepage
→ Healthcare pain section
→ Why Support Plus
→ Growth system section
→ Healthcare Solutions page
→ Case study / proof
→ Consultation CTA
→ Booking form
→ Calendar booking
→ CRM entry
→ Sales follow-up
UX logic
This flow is for high-level decision makers who want a strategic partner, not service details first. It should prioritize authority, outcomes, proof, and easy booking. That matches the company’s positioning as an outsourced growth department and long-term strategic partner.
4.2 User Flow B — Marketing Manager Flow
Goal: explore specific services and validate expertise.
Homepage
→ Services ecosystem
→ Digital Marketing & Performance page
→ Content / Media / CRM cross-links
→ Reporting / dashboards section
→ Start Audit CTA
→ Assessment result
→ Recommended bundle
→ Book consultation
UX logic
This flow is more detail-driven. The user wants strategy, performance structure, content strength, and reporting clarity. The service profile already supports performance, reporting, content, SEO, email, and analytics as connected functions.
4.3 User Flow C — Operations Manager Flow
Goal: solve follow-up, CRM, and process gaps.
Homepage
→ Pain points
→ Call Center & Sales Conversion section
→ Call Center Solutions page
→ Lead Qualification / Appointment Follow-Up / CRM Integration pages
→ Call Center Health Score tool
→ Results screen
→ WhatsApp or consultation
UX logic
This is where operational pain becomes conversion pain. Your medical readiness framework explicitly shows that weak call answering, weak WhatsApp use, no scheduling system, and slow response can kill ad performance.
4.4 User Flow D — Service-Intent Buyer
Goal: arrive from ads or search to one specific service and convert.
Google / Ad Landing
→ Service page
→ Problem section
→ Solution section
→ Benefits / deliverables
→ Related services
→ CTA
→ Form / WhatsApp / proposal
UX logic
This flow should use the same conversion discipline as the earlier service-page model: introduction, problem, solution, benefits, deliverables, CTA.
4.5 User Flow E — Mid-Intent Assessment User
Goal: not ready to book immediately, but willing to engage.
Homepage / Healthcare page / Tool page
→ Medical Growth Readiness Assessment
→ Step-by-step questions
→ Score + interpretation
→ Best-fit system recommendation
→ Book consultation / WhatsApp / email capture
UX logic
This is one of the strongest flows on the site because your uploaded assessment already covers brand strength, digital presence, ad readiness, content readiness, competition, and operational readiness with weighted scoring.
4.6 User Flow F — Partner / Reseller Flow
Homepage / footer / partnership CTA
→ Partnerships page
→ Partner model options
→ Apply / request discussion
→ Form
→ CRM routing to partnership pipeline
